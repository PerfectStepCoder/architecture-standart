Задание 4. Передача ставок в кол-центр

1) Разработайте ADR для новых изменений

Заполненый файл в формате markdown: ADR.md

2) Сформируйте список крупных задач для каждой системы из ADR для будущего планирования

    1. АБС (Автоматизированная банковская система)

        Разработка модуля расчета ставок
            - Реализация PL/SQL-процедур для ежедневного пересчета ставок на основе данных кредитного риска
            - Интеграция с Excel-отчетами (замена ручного ввода)
        Настройка автоматического экспорта данных
            - Разработка скрипта (Python) для выгрузки ставок в CSV
            - Реализация PGP-шифрования файлов
            - Настройка расписания (ежедневно в 8:00)
        Создание API для внутренних систем (отложить на Phase 2)
            - REST-эндпоинты для запроса актуальных ставок

    2. Интернет-банк

        Разработка формы подачи заявки на депозит
            - Интерфейс выбора условий депозита
            - Интеграция с SMS-шлюзом для подтверждения
        Реализация очереди заявок (RabbitMQ)
            - Настройка асинхронной отправки заявок в АБС
            - Механизм повторных попыток при ошибках
        Кэширование справочных данных
            - Развертывание Redis
            - Обновление кэша ставок 1 раз/сутки

    3. Кол-центр (внутренний)

        Модернизация CRM-интерфейса
            - Добавление виджета с актуальными ставками
            - История изменений ставок за 30 дней
        Настройка SFTP-клиента
            - Автоматическая загрузка файлов из банковского SFTP
            - Валидация и парсинг CSV
        Обучение операторов
            - Скрипты консультаций по новым продуктам

    4. Партнёрский кол-центр

        Организация защищенного файлообмена
            - Настройка SFTP-сервера для приема файлов
            - Внедрение PGP-шифрования
        Интеграция с партнёрской CRM
            - Автоматический импорт CSV в их систему
            - Тестирование формата данных

    5. Инфраструктура

        Развертывание SFTP-сервера
            - Выделенный хост с резервированием
            - Настройка прав доступа
        Мониторинг передач
            - Логирование успешных/неудачных выгрузок
            - Алёрты при сбоях

    6. Безопасность

        Генерация PGP-ключей
            - Отдельные ключи для банка и партнёра
            - Хранение в HSM (Hardware Security Module)
        Аудит доступа
            - Фиксация всех операций с файлами
