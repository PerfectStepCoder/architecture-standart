### <a name="_qmphm5d6rvi3"></a>**Решение**
Приведите диаграммы контекста и контейнеров в модели C4. Опишите там основные компоненты и интеграции всех элементов решения. 

Ссылка на диаграммы: https://drive.google.com/file/d/10JolH4EqacpdKC57Nbrcd_QIp0Ma2MCC/view?usp=sharing
(вкладки "Контекст (C4 Level 1)" и "Контейнеры (C4 Level 2)")

Логика решений:
    1) SFTP вместо API:
        - Партнёрский кол-центр не поддерживает API
        - Шифрование PGP обеспечивает безопасность
    2) Ежедневное обновление:
        - Ставки меняются редко (1 раз/день)
    3) Простота интеграции:
        - Используются существующие технологии (Python, SFTP)

### <a name="_bjrr7veeh80c"></a>**Альтернативы**

|Вариант|	Плюсы|	Минусы|
|-|-|-|
|API для кол-центра|Реальное время|Не поддерживается партнёром|
|Облачное хранилище|Масштабируемость|Дороже SFTP|

Недостатки выбранного решения:

    - Задержка данных: До 24 часов перед обновлением
    - Ручная проверка: Нет автоматического контроля целостности файлов

Риски:

    - Ошибки при ручном импорте в партнёрской системе
    - Утечка данных из-за слабого PGP-ключа

Рекомендации:

    - Автоматизировать проверку файлов (checksum)
    - Вести лог передач для аудита
    - Добавить оповещения при сбоях экспорта
